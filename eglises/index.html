Un quiz biblique en direct pour votre église

Une soirée de jeunesse, un camp, une veillée : vous projetez un code sur grand écran, chacun le saisit sur son téléphone, et toute l’assemblée répond en direct aux mêmes questions. Gratuit, sans rien installer.

Comment ça se passe

1. Vous créez le quiz. Depuis un téléphone ou un ordinateur : nombre de questions, catégories (personnages, paroles de Jésus, lieux…), niveau, temps par question.

2. Le code s’affiche sur grand écran. L’écran de l’animateur est fait pour être projeté : le code de la salle, puis les questions et les scores, lisibles de loin.

3. Chacun rejoint avec son téléphone. Pas de compte à créer, pas d’appli à installer : on saisit le code et son prénom dans le navigateur, et on joue — jusqu’à 100 participants.

4. Chaque réponse ramène au texte. La référence biblique s’affiche à chaque question : le quiz donne envie de rouvrir les Écritures, il ne s’y substitue pas.

Ce que ça demande

Un écran ou un projecteur, une connexion internet, et les téléphones que vos jeunes ont déjà dans la poche. Seul l’animateur crée un compte (gratuit — un e-mail et un pseudo, rien d’autre).

Ce que ça coûte — et ce que ça ne coûtera jamais

Rien, et ce n’est pas une période d’essai : Bible Horizon est un projet bénévole, gratuit pour toujours, sans publicité. Les données de votre assemblée ne sont ni exploitées ni revendues — l’appli fonctionne même sans compte pour les participants, et la philosophie du projet est de ne jamais mettre la pression à personne : pas de classements permanents, pas de relances, pas de culpabilisation.

Envie d’aller plus loin avec votre assemblée ?

Bible Horizon grandit avec les églises qui s’en servent : si vous aimeriez des outils pensés pour votre assemblée — ou simplement échanger sur vos besoins —, écrivez-nous. Chaque message reçoit une réponse.

Questions fréquentes

Combien de personnes peuvent participer ?

Jusqu’à 100 participants par quiz — de quoi couvrir une soirée de jeunesse, un camp ou une veillée d’église.

Les participants doivent-ils créer un compte ?

Non : ils saisissent le code affiché à l’écran et leur prénom, c’est tout. Seul l’animateur a besoin d’un compte gratuit.

Peut-on choisir les questions ?

Vous choisissez les catégories, le niveau, le nombre de questions et le temps de réponse. Chaque question cite sa référence biblique (Segond 1910).

Faut-il installer quelque chose ?

Non, tout se passe dans le navigateur — sur l’ordinateur qui projette comme sur les téléphones des participants.

Est-ce vraiment gratuit pour une église ?

Oui, sans condition ni période d’essai : le projet est bénévole et le restera. Aucune donnée n’est revendue.
